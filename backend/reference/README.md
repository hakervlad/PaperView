# Historische Serverarchitektur

Diese Android-Clientdateien und Tests gehören zur abgelösten FastAPI-Architektur. Sie werden **nicht** in die eigenständige Android-App kompiliert und sind keine aktuellen Akzeptanztests. Für eine reproduzierbare historische Ausführung den Stand `f953054` verwenden; nicht in die lokale App zurückkopieren.

Das Python-Backend in `../paperview` und seine Tests bleiben als Referenz erhalten. Die aktuelle App benötigt es nicht. Nur `../export_local.py` dient noch der sicheren, nur lesenden Übernahme vorhandener Serverdaten.

Aktuelle Architektur und Einrichtung: [Lokale Android-App](../../docs/LOCAL_ANDROID.md).
